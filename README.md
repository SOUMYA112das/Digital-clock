This Python project is a digital clock application built with Tkinter, providing a clean and modern graphical interface.
The program displays the current time in a 12-hour format with AM/PM and also shows the complete date, including the day, month, and year.
The time and date automatically refresh every second using the after() method, ensuring accurate real-time updates. 
The design features a black background for contrast, with the time displayed in cyan and the date in lime green, giving it a stylish look.
It demonstrates how Python can be used to build functional desktop applications with GUI elements, combining simplicity with utility.
